## 🌟 Overview

This portfolio is designed with a focus on clean UI/UX and high performance. It effectively communicates my technical stack, project history, and professional philosophy. The development process integrated **AI-assisted coding** to optimize structure and **OneCompiler** for rapid logic testing and prototyping.

## ✨ Key Features

* **Modern & Responsive Design:** Fully optimized for all screen sizes (Mobile, Tablet, Desktop).
* **Dynamic Project Showcase:** A curated section displaying my best work with direct links to repositories and live demos.
* **Interactive UI:** Smooth scrolling and interactive elements to enhance user engagement.
* **Optimized Performance:** Lightweight code structure for lightning-fast loading speeds.
* **AI-Enhanced Workflow:** Leveraged AI tools for code optimization, debugging, and content structuring, ensuring a high-quality final product.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** CSS
* **Development Tools:** VS Code, OneCompiler, ChatGPT (AI-Assisted Development)
* **Deployment:** GitHub Pages

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/masoumeh78/Personal-Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Personal-Portfolio
   ```

3. **Open the project:**
   Simply open `index.html` in your browser or use a Live Server extension in VS Code.
